# Why React + Vite + Tailwind?

- **React** is the most used library to build web interfaces, so there are tutorials for everything.
- **Vite** starts in milliseconds and refreshes the browser every time you save.
- **Tailwind CSS** lets you style elements with classes like `text-xl font-bold`, without switching files.

DevStarter adds a small welcome page with a button so you can see all three working together.
