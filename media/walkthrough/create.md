# Create a project

Run **DevStarter: New Project** from the Command Palette (`Ctrl+Shift+P`), or click **✨ New Project** in the status bar.

**Never programmed before?** Pick an idea: *a 3D website*, *a game*, *a blog*, *a mobile app*… DevStarter chooses the right technology for you, so you only have to name your project.

**Know what you want?** Pick the technology, then:

1. **Add a backend?** Frontends and mobile apps can get any backend, already connected.
2. **Database?** SQLite, PostgreSQL, MySQL or MongoDB, ready to use.
3. **Libraries:** Three.js, GSAP, Phaser, Zustand, Zod… Many come with a demo page.
4. **Extras** like Tailwind CSS, Git, Docker or Prettier.

Then sit back. If something is missing on your computer (Node.js, Python, PHP…), DevStarter offers to install it.
