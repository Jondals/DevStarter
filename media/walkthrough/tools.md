# Check your tools

Every kind of project needs some programs installed on your computer:

| To build… | You need |
| --- | --- |
| Websites and JavaScript apps | Node.js (npm comes with it) |
| Python APIs and scripts | Python |
| Laravel | PHP and Composer |
| Anything you want to save in history | Git |

Run **DevStarter: Check My Tools** to see what you have. Anything missing can be installed in one click. You don't need to search download pages.

And if you skip this step, no problem: when you create a project, DevStarter checks again and offers to install what is missing.
