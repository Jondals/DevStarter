# Run it and make changes

When the project is ready, choose **Open Project**. DevStarter will:

- open the main file so you can start editing,
- show **GETTING_STARTED.md** with the commands you need,
- start the **dev server** in a terminal.

Open the URL shown in the terminal (for example `http://localhost:5173`), change some text in the editor and save. Your browser updates by itself. 🎉
